Фреймворк aiogram — это современная асинхронная библиотека для разработки Telegram-ботов на Python 3.8+.
Главные преимущества aiogram 3: поддержка встроенного FSM (конечных автоматов), роутеров (Routers), фильтров команд и валидация через Pydantic v2.
Для обработки нажатий инлайн-кнопок используется CallbackQueryHandler и фабрика колбэков CallbackData.
